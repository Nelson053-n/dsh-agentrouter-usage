# Usage ledger — `@local/usage-ledger`

Host-половина панели «Использование» для DeepSeek Harness.

## Установка

Устанавливается как локальный bundle через менеджер плагинов Harness. Нужны Web/Desktop-профиль и клиентская половина `@local/token-usage`. Для AgentRouter нужен отдельно установленный `dsh-llm-agentrouter@2.6.1`.

[Полная инструкция установки и подключения кабинета](../../README.md).

## Маршруты

Все сводки требуют авторизации Harness / Connection admission:

- `GET /token-usage/summary` — токены по моделям, провайдерам, дням, проектам и сессиям;
- `GET /token-usage/balances` — статусы источников баланса и optional квота ключа AgentRouter;
- `GET /token-usage/codex` — отдельный локальный источник Codex CLI;
- `GET /token-usage/agentrouter` — условно доступная сводка квоты API-ключа;
- `GET /api/token-usage/agentrouter/account` — баланс кабинета и описание подключения без токена;
- `POST /api/token-usage/agentrouter/account/binding` — browser-only подключение/отключение кабинета.

Кабинет AgentRouter читается через `/api/user/self` с Access token и `New-Api-User`; публичный `/api/status` запрашивается без токена. ID проверяется до сохранения. Приватные поля профиля не передаются в UI. Управляющий токен сохраняется только через credential service, одним plugin-owned grant, и привязан к согласованному HTTPS origin.

Квота ключа `/api/usage/token/` — отдельный optional контракт: некоторые версии AgentRouter его не предоставляют. Отказ/404 не превращается в нулевой баланс кабинета. Валюта подтверждается status API; иначе выводятся исходные единицы квоты.

## Локальный расход

Сессии перечисляются через `ctx.sessionQuery`; расход складывается по `assistant/message.usage` и записанному `message.source.provider/model`. Данные не пересчитываются по видимой части чата. `summary.byProvider` содержит отдельно токены, ответы и число сессий AgentRouter; они уже входят в общий расход DSH.

Повторно импортированные журналы могут увеличить агрегат. День — локальная дата Host. Первый расчёт может прочитать полные журналы профиля; последующие результаты кэшируются на 45 секунд.

## Дополнительные источники

При открытии панели могут запрашиваться настроенные локальные источники OpenRouter/Anthropic и Codex CLI. Codex-источник может читать собственный auth-файл CLI и локальные rollouts. Ни эти файлы, ни credential store не входят в дистрибутив.

Кэш баланса AgentRouter — 60 секунд; явно помеченные предыдущие данные сохраняются при временной ошибке максимум на 15 минут. Смена/удаление токена и отказ прав сбрасывают старые данные. Подключение не выполняет inference-запросов.
