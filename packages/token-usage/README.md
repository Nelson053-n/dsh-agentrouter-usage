# Token usage and cost — `@local/token-usage`

Web UI для DeepSeek Harness: страница «Использование», оценка стоимости сессии и карточка AgentRouter с формой подключения кабинета.

## Установка

Это готовая lazy-factory браузерного плагина; сборка и установка своей копии React не нужны. Устанавливайте этот каталог через менеджер плагинов Harness вместе с Host-половиной `@local/usage-ledger`. Для моделей и endpoint AgentRouter нужен отдельно установленный `dsh-llm-agentrouter@2.6.1`.

[Полная инструкция](../../README.md).

## Кабинет AgentRouter

**Использование → AgentRouter → Подключить кабинет**:

- Access token кабинета и числовой `New-Api-User`, не ключ моделей `sk-…`;
- видимый HTTPS адрес назначения и отдельное пользовательское согласие;
- проверка токена/ID на Host перед сохранением;
- настоящий баланс кабинета и optional накопленный расход/число запросов;
- отдельная квота ключа, когда её API доступен, и отдельные токены/ответы/сессии DSH;
- время обновления, ошибки и явная пометка устаревших данных;
- отключение кабинета с подтверждением без изменения ключа моделей.

Токен не отправляется в чат, не сохраняется в browser storage и не возвращается API. Поле пароля очищается после запроса. Локальный credential store не является изоляцией от процессов того же OS-пользователя.

## Оценка стоимости

Стоимость вычисляется по встроенным таблицам тарифов для ID/семейства модели и исходным категориям токенов: ввод без кэша, чтение/запись кэша и вывод. Это **оценка, не счёт AgentRouter**. Неизвестная модель использует явно помеченный базовый тариф. Версии тарифов и условия провайдеров могут меняться.

Сводка по моделям/дням/проектам и текущая сессия читаются из Host ledger; переключение модели не меняет атрибуцию уже записанных ответов. Дополнительный Codex CLI источник учитывается отдельно от DSH.

Интерфейс локализован на русский, английский и китайский. Карточки используют тему Harness. В репозиторий намеренно не включены скриншоты с личными данными аккаунта.

## Проверка

```sh
node test/smoke.mjs
```

Тест проверяет формат браузерного bundle, регистрации slots, набор переводов и арифметику. Он не заменяет визуальную проверку в подключённой странице. [Политика безопасности](../../SECURITY.md).
